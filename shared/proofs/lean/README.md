# Lean proofs for lakers-shared

Panic-freedom proofs for `lakers-shared`, using hax's Lean backend
(Charon → Aeneas → Lean).

## Layout

- `LakersShared/Extraction/`: generated by hax on every extraction; do not edit.
- `LakersShared/Assumptions/`: models for external items, seeded once from
  `Extraction/*_Template.lean`; edit by hand.
- `LakersShared/Verification/`: the proofs.

## Requirements

- `cargo-hax` matching the `hax-lib` version in the root `Cargo.toml`
- [elan](https://github.com/leanprover/elan)

Charon, Aeneas and Lean versions are pinned in the root `hax.toml`.
`cargo hax tools install` fetches them.

## Extract

From the repository root:

```
cargo hax -C --manifest-path shared/Cargo.toml \; into lean --charon-args="--start-from crate::buffer"
```

`--manifest-path` is needed because the root is a virtual workspace.
`--start-from` lists the modules extracted so far.

## Check

```
cd shared/proofs/lean
lake build
```

After re-extracting, compare `Assumptions/*` against the regenerated
`Extraction/*_Template.lean` for new holes to fill.
